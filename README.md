# 🩺 Diabetes Prediction using Machine Learning

A machine learning project that predicts whether a person is likely to have diabetes based on health-related parameters. The project includes data analysis, preprocessing, visualization, model building, and evaluation using Python and Scikit-learn.

## 📌 Project Overview

The goal of this project is to build a machine learning classification model that can predict diabetes outcomes from medical attributes such as glucose level, blood pressure, BMI, age, and other health-related features.

This project demonstrates an end-to-end machine learning workflow, from exploring the dataset to training and evaluating a predictive model.

## 📊 Dataset

The project uses the **Pima Indians Diabetes Dataset**, which contains patient health information and a target variable indicating whether diabetes was present.

### Features

* Pregnancies
* Glucose
* Blood Pressure
* Skin Thickness
* Insulin
* BMI
* Diabetes Pedigree Function
* Age
* Outcome

**Outcome:**

* `0` → Non-Diabetic
* `1` → Diabetic
